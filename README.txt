RODY BIRTHDAY WEBSITE
======================

Open index.html in a browser.

Music:
The uploaded MP3 is already included at:
assets/caflt-el-la3ba.mp3

The website starts the music after the visitor interacts with the page.

Birthday countdown:
Target date = 29 September 2026 (Egypt UTC+3).

Photos:
The three memory cards are visual placeholders. To add photos later, replace the
placeholder blocks in index.html with <img> elements, or ask for a customized
version.

The design uses a "game / queen / cards / sparkle / heart" visual theme inspired
by the song title and birthday mood, without reproducing song lyrics.
